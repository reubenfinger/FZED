FZED

Optional software for the Casio FZ-1 sampler, with its browser editor.

  • Open the editor (Chrome or Edge)
  • Read the manual
  • Download the FZED disk for an HxC (A FZ1_FZED.hfe)
  • Download the raw disk image (FZ1_FZED.img)
  • Download the editor and manual (FZED.zip, works offline)
